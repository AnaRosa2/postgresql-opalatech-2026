## Sobre o Minicurso

Este minicurso apresenta os fundamentos do PostgreSQL aplicados ao desenvolvimento web. Durante as atividades serão abordados conceitos de bancos de dados relacionais, modelagem de tabelas, relacionamentos, comandos SQL essenciais e integração com aplicações web utilizando Supabase.

## Conteúdo

* Banco de Dados Relacional
* PostgreSQL
* Supabase
* Modelagem de Dados
* Tipos de Dados
* Constraints
* CRUD
* JOINs
* Projeto Final
