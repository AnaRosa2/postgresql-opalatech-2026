## Sobre o Minicurso

Este minicurso apresenta os fundamentos do PostgreSQL aplicados ao desenvolvimento web. Durante as atividades serão abordados conceitos de bancos de dados relacionais, modelagem de dados, relacionamentos entre tabelas, comandos SQL essenciais e integração com aplicações web utilizando Supabase.

As atividades práticas utilizam uma base de dados fictícia de gerenciamento hoteleiro, permitindo explorar cenários reais de consultas, relacionamentos e manipulação de dados.
